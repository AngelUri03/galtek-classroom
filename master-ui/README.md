# Galtek Classroom Master UI

Foundation del Master UI para escritorio.

## Stack

- React 18
- TypeScript
- Webpack 5
- Sin Vite
- Sin Tauri por ahora

## Comandos

```powershell
npm install
npm run typecheck
npm run build
npm start
```

Los datos visibles del dashboard Aula viven en `src/mock/mockClassroomDashboard.ts` y son placeholders locales para 20A. No hay conexion a APIs reales en este paso.
